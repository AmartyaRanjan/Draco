## Where Draco deliberately differs
- LangGraph stays the graph engine; Draco does not model graphs.
- Security enforcement (policy, permissions, approval, budgets) lives in the runtime, never in prompts, and remote MCP text is treated as data.
- Telemetry failures are isolated, policy failures are fatal, and both behaviours are tested.
